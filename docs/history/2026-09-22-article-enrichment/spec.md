# 筆記全文與 AI 摘要規格

日期：2026-09-22。來源：grilling 訪談 Q1–Q14，使用者確認並授權開發。

- 僅目前 Markdown 筆記：抓取原文全文、產生 AI 摘要、抓取全文並摘要。reader 不增加操作。
- URL 欄位依序 feed_reader_url、source、url，可設定；衝突選擇，缺少提示補入。
- 公開 HTTP(S) HTML 擷取與 Readability 正文抽取，共用 sanitizer 後轉 Markdown。無登入、付費牆、JS 瀏覽器或 proxy。
- 原文規則多組排序，支援 heading 區塊與 property/value 對應整份正文。第一匹配規則優先，多候選由使用者選擇；標題至下一同級／高級標題。新區塊隱藏標記精確辨識。
- 已有原文區塊取代（包含該區人工修改），否則文末附加。範圍外及 Properties 保留。
- 摘要只讀全文，排除 Properties／摘要。無匹配提示擷取後摘要或本次使用正文。組合命令擷取失敗停止。
- 摘要預設繁體中文概述＋3–5 重點，提示詞可修改；文章前方 AI 摘要區塊重跑取代。
- 本地 CLI：Codex、Claude Code、OpenCode、pi 與自訂；偵測、刷新、預設、路徑、參數、測試。沿用 CLI 登入及模型，不自動安裝或使用略過權限的參數。
- 文章作為不可信資料輸入，CLI 不負責寫入 vault；插件掌管寫入。CLI 可以依既有設定使用雲端模型。
- 提示詞／原文規則放插件設定；CLI 路徑／參數／預設／偵測依本機保存。
- 背景、取消、同篇單工作；固定啟動時筆記，執行中有修改需顯示結果由使用者決定，卸載不遲到寫入。

驗收：原文範圍／URL／輸入選擇、擷取錯誤與清理、四 CLI 輸出 adapter、失敗／取消／競爭寫入、設定與命令整合。mock 與實機證據分列。

## 後續覆蓋條款：僅摘要取文（2026-09-22）

使用者後續要求優先於上述初始訪談：單獨摘要無全文時自動背景取文且只寫摘要，取消原本的取文／本次正文詢問。新摘要在原內容前，新全文在原內容後，已有對應區塊只更新該區；整正文規則不可用來覆寫整篇，未知內容保留。組合命令仍同時寫入全文與摘要。
