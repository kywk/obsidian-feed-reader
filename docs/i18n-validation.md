## 功能範圍

- 英文、繁體中文涵蓋閱讀器、來源管理、設定、命令與操作提示。
- 預設跟隨 Obsidian，可指定 en 或 zh-TW；未支援語言退回英文。
- 語言設定成功寫入後，重新啟用插件才套用。寫入失敗恢復原設定，選擇語言不清除其他未套用草稿。
- 來源名稱、內容、筆記、模板、摘要提示詞與穩定資料 ID 保持原值。底層技術診斷可保留原文。
